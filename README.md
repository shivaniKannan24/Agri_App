# 🌤️ Weather Forecast Web App

A simple and elegant **Weather Forecasting Web Application** built using **Flask**, **HTML/CSS**, and the **OpenWeather API**.  
Users can enter a city name and get the current temperature, humidity, wind speed, and weather conditions in real-time.

---

## 🚀 Features

- Search weather by **city name**
- Displays:
  - Temperature 🌡️
  - Humidity 💧
  - Wind Speed 🌬️
  - Weather Condition ⛅
- Clean and responsive user interface
- Uses **OpenWeather API** to retrieve accurate weather data

---

## 🛠️ Technologies Used

| Technology | Purpose |
|-----------|---------|
| Python (Flask) | Backend framework |
| HTML5 | UI structure |
| CSS3 | Styling & layout |
| JavaScript (optional) | Dynamic UI updates |
| OpenWeather API | Real-time weather data |

## ⚙️ Setup & Installation

### 1️⃣ Install Python

Check if Python is installed:

python --version

2️⃣ Install Dependencies
Navigate to the project folder and run:

pip install flask requests
(or)

pip install -r requirements.txt

3️⃣ Add Your OpenWeather API Key
Open app.py and replace:
API_KEY = "YOUR_API_KEY"
Get your free API key from:
https://openweathermap.org/api

4️⃣ Run the Application
python app.py

5️⃣ Open in Browser
http://127.0.0.1:5000/

🌐 API Used
OpenWeather API
https://openweathermap.org/api
